# 🤖 AI Study Assistant

AI Study Assistant is a Flutter-based mobile application designed to help
students study, create notes, practice quizzes, and track quiz history in
one place.

---

## 📌 Features

- 📚 Create and manage study notes
- 📝 Generate and practice quizzes
- 📊 View quiz history
- 💾 Store notes and quiz data locally
- 🔄 Easy navigation between screens
- 📱 Responsive Flutter UI
- 🎯 Student-friendly study interface
- 🤖 AI-assisted learning features

---

## 🛠️ Technologies Used

- Flutter
- Dart
- Hive
- Material UI
- Local Storage
- Android SDK
